📌 B-Axis Zero Convention

( B0 = T-slots facing Z+ direction (facing column) ) ( B90 = T-slots rotated 90° CCW viewed from above ) ( B180 = T-slots facing Z- (away from column) ) ( B270 = T-slots rotated 270° CCW viewed from above ) ( Positive rotation direction: CCW viewed from above ) ( Use M10/M11 to clamp/unclamp BEFORE/AFTER index ) G91 G28 B0 ( B-axis return to zero reference ) M10 ( Clamp B-axis )
Always verify B0 direction on your specific machine — Toyoda sometimes ships with B0 facing the APC door side depending on configuration.
Phase 1 — Open CIMCO Edit and Locate Base Machine
  1. Launch CIMCO Edit 8 (or CIMCO Suite). Ensure Machine Simulation module is licensed/activated — check Help → About → Modules.
  2. Go to Machine Simulation → Machine Manager (or press F8). The Machine Manager dialog lists all installed machine definitions.
  3. In the machine list, locate an existing 4-axis horizontal machining center. Common built-in candidates:
    • Generic 4-Axis HMC
    • Fanuc 4-Axis Mill
    • Any machine with a B rotary axis on the table side (not the head).
    If none exists, look for a 3-axis vertical mill and you will add the B-axis manually in Phase 3.
  4. Select the base machine. Click Copy / Clone (not Edit). Name the copy: TOYODA_NH550SX.
  5. Click Edit on the new TOYODA_NH550SX entry. The Machine Editor opens.
Phase 2 — Machine Identity & Control Settings
  1. In the General tab of Machine Editor, set:
    • Name: TOYODA NH550SX
    • Description: Toyoda NH550SX HMC 4-axis B-rotary Fanuc 31i-B5
    • Machine Type: Mill (or Milling Center)
  2. In the Control / Post tab (may be labeled CNC Control or Controller):
    • Set Controller: Fanuc
    • Set Control Model: 31i or 31i-B if available in the dropdown
    • Enable Custom Macro B support (G65/G66 recognition)
    • Enable Rigid Tapping (M29 + G84)
  3. Set Units to Metric (mm) — the NH550SX native unit is metric. Your NC programs can use G20/G21 to switch.
  4. Set Linear resolution: 0.001 mm and Rotary resolution: 0.001 deg.
Phase 3 — Axis Definitions
  1. Navigate to the Axes tab. You should see a list of defined axes. Delete or rename any axes that do not match X, Y, Z, B.
  2. Define or verify X-Axis (linear):
    • Type: Linear · Direction: +X
    • Min: -550 · Max: 0 (or 0 to 550, depending on your machine home convention)
    • Rapid: 60000 mm/min · Max feed: 60000 mm/min
  3. Define or verify Y-Axis (linear):
    • Type: Linear · Direction: +Y
    • Min: 0 · Max: 600
    • Rapid: 60000 mm/min
  4. Define or verify Z-Axis (linear):
    • Type: Linear · Direction: +Z
    • Min: -600 · Max: 0
    • Rapid: 60000 mm/min
  5. Add or configure B-Axis (4th axis — rotary):
    • Type: Rotary
    • Rotation plane: XZ (rotates around Y — this is correct for an HMC B-axis table)
    • Min: -9999 · Max: 9999 (unlimited rotation)
    • Rapid: 14400 deg/min (= 40 RPM)
    • Axis letter: B
  6. Set axis home positions (these are the G28 return values in simulation):
    X=0, Y=600, Z=0, B=0 — adjust to match what your machine displays at reference.
The B-axis on an HMC rotates the TABLE, not the head. In CIMCO's kinematic chain the B-axis node must be placed on the WORKPIECE side, not the spindle side. Incorrect placement will produce wrong 4-axis simulation paths.
Phase 4 — Kinematic Chain (Critical for HMC)
  1. Open the Kinematics tab (sometimes called Machine Structure or Component Tree).
  2. The correct kinematic chain for the NH550SX is:
    Machine Base → [Z-column] → [X-slide] → [Y-slide] → Spindle (tool)
    Machine Base → [B-rotary table] → Workpiece (pallet)
  3. Ensure the B-axis node is a child of Machine Base, not a child of any spindle-side node.
  4. Set the B-axis pivot point (center of rotation in machine coordinates). This should be the center of the pallet table. Typical value: X=275, Y=0, Z=center-of-table-face (measure from your machine).
  5. If CIMCO supports 3D model import, load STL/STEP components for the machine body, column, spindle head, and pallet. Place each under the correct kinematic node so they move with the axes in simulation.
Phase 5 — M-Code & G-Code Configuration
  1. Go to the M-Codes tab. Add Toyoda-specific M-codes that CIMCO must recognize and act on. At minimum configure:
    • M10 → Action: Clamp rotary axis B
    • M11 → Action: Unclamp rotary axis B
    • M06 → Action: Tool change (already present in most templates)
    • M19 → Action: Spindle orient
  2. Go to the Tool Change tab. Set:
    • Tool change position — typically G53 Z0 (Z machine home)
    • ATC trigger: M06
    • Magazine size: 60
  3. In G-Code Groups, verify Group 1 (motion modes) includes G00, G01, G02, G03 and Group 14 (canned cycles) includes G73–G89.
  4. Save the machine definition. Click OK / Save and return to Machine Manager.
CIMCO Edit stores machine definitions in: C:\ProgramData\CIMCO\CIMCOEdit8\Machines\ — back up your .mch file after configuration.
Phase 6 — Load Machine into Simulation
  1. Open or create a test NC program in CIMCO Edit.
  2. Go to Machine Simulation → Simulate (or press F5).
  3. In the simulation toolbar, click the Machine dropdown and select TOYODA NH550SX.
  4. Load a stock block: Stock → Define Stock — set dimensions appropriate to your test program.
  5. Set the Work Offset origin (G54) relative to the stock. Drag the WCS indicator in the 3D view or enter coordinates manually.
  6. Press Play (or step through with F10). Confirm the B-axis rotates the table and X/Y/Z move the spindle.

Cylindrical Interpolation — G07.1

▶ G07.1 — Wrap Groove on Cylinder

( Cylindrical interpolation — mills a groove on OD ) ( Programs B-axis as linear axis (circumference) ) ( Radius must match part radius ) G00 Z5.0 ( Clear Z before enabling G07.1 ) M11 ( Unclamp B ) G07.1 B75.0 ( Enable cyl interp; 75mm = part radius ) ( Now B values are in mm (arc length), not degrees ) G90 G01 B0 Z0 F100 G01 B100.0 Z-30.0 ( Helical groove ) G01 B200.0 Z0 ( Return ) G07.1 B0 ( Cancel cylindrical interpolation ) M10 ( Clamp B )
G07.1 B<radius> activates cylindrical interpolation. Cancel with G07.1 B0. The B value in the enable block is the cylinder radius in mm, NOT a position.

Rigid Tapping (G84 + M29)

▶ M29 Rigid Tapping — Correct Sequence

( RIGID TAPPING — M8x1.25 thread, 20mm deep ) ( Feed = Pitch × RPM = 1.25 × 800 = 1000 mm/min ) G91 G28 Z0 T5 M06 ( Load M8 tap ) G90 G43 H5 M29 S800 ( Rigid tapping mode — set speed here ) M49 ( Lock override at 100% ) G54 G00 X50.0 Y50.0 G43 Z5.0 G84 X50.0 Y50.0 Z-20.0 R2.0 P200 F1000 X100.0 X150.0 G80 M48 ( Restore override ) G00 Z50.0 M05
M29 MUST appear before G84 and after the S word. Omitting M29 uses standard (non-rigid) tapping which will strip threads on a rigid machine spindle.

In CIMCO simulation, confirm the rotation arrow on the B-axis 3D model matches your machine. If the 3D rotation is opposite to physical machine, negate the B-axis direction in the axis definition or toggle the "Reverse" checkbox.
For programs using only 90° index positions, always use absolute B values (G90): B0, B90, B180, B270. Avoid incremental (G91) for indexed positions — absolute prevents accumulated error and is easier to verify in simulation.
