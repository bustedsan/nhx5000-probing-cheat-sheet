⚠ Model Name Discrepancy — Read First
The machine name "NH550SX" does not match any documented Toyoda/JTEKT product. All available sources (JTEKT official site, TECHSPEX, dealer listings, Practical Machinist forums) consistently name the Toyoda 550mm-pallet horizontal machining center as the FH550SX. The "NH" prefix is used by DMG Mori (NHX5000, NHX4000), not Toyoda.

Action: Check the machine nameplate for the exact model number before using this guide for real programming. This document uses FH550SX specifications. If your machine is genuinely labeled NH550SX it may be an older or regional variant — consult Toyoda/JTEKT directly.

Phase 1 — Open CIMCO Edit and Locate Base Machine
  1. Launch CIMCO Edit 8 (or CIMCO Suite). Confirm Machine Simulation is licensed — check Help → About → Modules. You need the Machine Simulation license key active.
  2. Go to Machine Simulation → Machine Manager (or press F8). The Machine Manager lists all installed machine definitions.
  3. Locate an existing 4-axis horizontal machining center in the list. Good starting points:
    • Any machine labeled "HMC" or "Horizontal 4-Axis"
    • A machine with a B rotary axis on the table side (not the head)
    • If none exist, use a generic 3-axis vertical and add the B-axis in Phase 3
  4. Select the base machine. Click Copy / Clone — never edit the original. Name the copy: TOYODA_FH550SX
  5. Click Edit on the new copy. The Machine Editor opens with multiple tabs.
Phase 2 — Machine Identity & Control Settings
  1. General tab — set Name: TOYODA FH550SX, Description: Toyoda FH550SX HMC B-rotary 4-axis Fanuc 31i, Type: Mill / Machining Center
  2. Control / CNC Controller tab:
    • Controller: Fanuc
    • Model: 31i or 31i-B (pick the closest available)
    • Enable: Custom Macro B (G65/G66), Rigid Tapping (M29+G84), Extended work offsets (G54.1)
  3. Set Units: Metric (mm). The FH550SX is a metric machine natively. G20/G21 in the NC program can switch.
  4. Set Linear resolution: 0.001 mm and Rotary resolution: 0.001 deg
Phase 3 — Axis Definitions
  1. Go to Axes tab. Remove or rename any axes that don't match X, Y, Z, B.
  2. X-Axis: Type=Linear, Letter=X, Min=-740, Max=0, Rapid=60000 mm/min, Kinematic: Spindle side
  3. Y-Axis: Type=Linear, Letter=Y, Min=0, Max=800, Rapid=60000 mm/min, Kinematic: Spindle side
  4. Z-Axis: Type=Linear, Letter=Z, Min=-800, Max=0, Rapid=60000 mm/min, Kinematic: Spindle side
  5. B-Axis (4th): Type=Rotary, Letter=B, Rotation Plane=XZ (rotates around Y), Min=-9999°, Max=9999°, Rapid=14400 °/min, Kinematic: WORKPIECE side, Clamp M=M10, Unclamp M=M11
  6. Set home positions: X=0, Y=800, Z=0, B=0
The B-axis rotation plane must be XZ (axis of rotation = Y-axis) for a horizontal machining center where the rotary table lies flat on the machine base. Setting this wrong makes B rotate the spindle head instead of the table.
Phase 4 — Kinematic Chain (Critical for HMC)
  1. Open the Kinematics / Structure tab. The chain for an HMC has two independent branches from the machine base.
  2. Spindle branch (tool moves):
    Machine Base → Z-column → X-slide → Y-slide → Spindle (tool holder)
  3. Table branch (part moves):
    Machine Base → B-rotary table → Pallet → Workpiece
  4. Confirm B is under Machine Base — not under any spindle-side node.
  5. Set the B-axis pivot point to the center of the pallet surface (see Axis Config tab for typical values).
Phase 5 — M-Code Configuration
  1. Go to M-Codes tab. Add recognized M-codes at minimum:
    • M10 → Clamp rotary axis B
    • M11 → Unclamp rotary axis B
    • M06 → Tool change (usually pre-configured)
    • M19 → Spindle orient
    • M29 → Rigid tapping mode
  2. For machine-specific M-codes (coolant types, APC, door, chip conveyor), add them to the recognized list even if CIMCO can't simulate the physical action — this prevents "unknown M-code" warnings stopping the simulation.
  3. Tool Change tab: Set tool change position to G53 Z0 (Z machine home), ATC trigger = M06, Magazine = 60 tools.
  4. Save and return to Machine Manager. The machine definition file is stored at:
    C:\ProgramData\CIMCO\CIMCOEdit8\Machines\TOYODA_FH550SX.mch
Back up your .mch file immediately after configuration. Share it with other CIMCO users on the same shop floor so everyone simulates with the same machine model.
Phase 6 — Load and Test
  1. Open a test NC program. Go to Machine Simulation → Simulate (F5).
  2. Click Machine dropdown → select TOYODA FH550SX.
  3. Define stock: Stock → Define Stock with a 200×200×200mm cube.
  4. Set G54 origin on the stock face. Press Play or step with F10.
  5. Verify: B-axis indexes the TABLE (not the spindle), XYZ move the column/spindle, M06 changes tool.

⚠ Critical Disclaimer on M-Codes
M-codes are split into two categories on all Fanuc-controlled machines:
• Fanuc standard M-codes (M00–M09, M19, M29, M30, M48, M49, M98, M99) — same on every Fanuc machine. These are CONFIRMED.
• Machine-builder M-codes (M10 and above for machine functions) — assigned by Toyoda/JTEKT in the PLC ladder. These CANNOT be confirmed without the actual Toyoda FH550SX Programming Manual.

The machine-builder M-codes shown below are the most common assignments found on Fanuc-based horizontal machining centers and are reported by Toyoda machine owners in machinist forums. Verify every M-code above M09 against your machine's M-code table in the Toyoda operator manual before use.

B-Axis Direction Convention
( FH550SX B-axis — viewed from above (+Y): ) ( Positive B = CCW rotation ) ( B90 (Left face — +X side) ) ( | ) ( B180 (rear) ---+--- B0 (front — toward column) ) ( | ) ( B270 (Right face — -X side) ) ( B0 = pallet T-slots face column (+Z direction) ) ( B90 = pallet T-slots face +X side ) ( B180 = pallet T-slots face away from column ) ( B270 = pallet T-slots face -X side ) ( Fanuc 31i indexes B via shortest path by default. ) ( B0 → B270 = -90° CW (shorter than +270° CCW). ) ( Use absolute B values (G90) to ensure correct index. )
Verify B0 direction on your machine physically. Index to B0 and check which pallet face points toward the column. If it differs from the convention above, update your work offset reference accordingly.
Canned Cycles After B-Axis Index
After indexing and clamping B (M10), standard Fanuc canned cycles operate normally. The key is selecting the correct plane (G17/G18/G19) to match the actual drilling direction on the indexed face.

Plane Selection by Face

On an HMC, all indexed faces present a Z-direction drilling surface to the spindle when correctly indexed. G17 (XY plane, Z drill direction) is correct for all 4 faces when using 90° indexing. You only need G18/G19 for special angular or horizontal boring operations.
Rigid Tapping — M29 + G84
( RIGID TAPPING — M8×1.25, 20mm deep ) ( Feed = Pitch × RPM = 1.25 × 800 = 1000 mm/min ) G91 G28 Z0 G91 G28 Y0 T5 M06 ( Load M8 tap ) G90 G43 H5 M29 S800 ( Enable rigid tapping, S=800 RPM ) M49 ( Lock override at 100% ) G54 G00 X50.0 Y50.0 G43 Z5.0 G84 X50.0 Y50.0 Z-20.0 R2.0 P200 F1000 X100.0 X150.0 G80 M48 ( Restore override ) G00 Z50.0 M05 M09
M29 must appear in the block BEFORE G84 with the S word. Without M29, the Fanuc 31i will use floating tap mode which can break taps in rigid machine spindles.
