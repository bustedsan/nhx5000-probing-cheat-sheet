NX 2412 Note

NX 2412 ships with an updated Machine Tool Builder that supports direct import of .step files as collision geometry. All instructions in this kit use the 2412 MTB UI paths. If you're on an earlier build, menu locations may differ slightly.

Machine Tool Builder — NH550SX

The NX Machine Tool Builder (MTB) defines the kinematic chain, travel limits, and collision geometry. Follow these steps in order.

Step 1 — Create a New Machine

Open Machine Tool Builder

In NX 2412: Menu → Manufacturing → Machine Tool Builder — or press Ctrl+Alt+M. Select New Machine.

Set Machine Type

Choose Milling. Machine configuration: Horizontal Machining Center. Number of axes: 4.

Name and Save

Machine Name: TOYODA_NH550SX. Save location: UGII_CAM_LIBRARY_DIR/machines/. This makes it available to all CAM sessions.

Step 2 — Define the Kinematic Tree

The NH550SX is a B-on-table / moving-column architecture. Build the tree exactly as shown:

Kinematic Tree — NH550SX
World (fixed base)
 └─ X_AXIS        ← linear, table traverses Left/Right
     └─ B_AXIS    ← rotary, table rotates about Y (vertical axis of table)
         └─ TABLE ← fixture / pallet mounts here (workpiece side)

 └─ Y_AXIS        ← linear, column moves Up/Down
     └─ Z_AXIS    ← linear, spindle moves In/Out (toward table)
         └─ SPINDLE ← tool mounts here
B-Axis Pivot Location

The B-axis rotation center is at the center of the rotary table surface. Set the B-axis joint origin to the table center X=0, Y=0 (table surface height), Z=0 in machine coordinates. This must match your control's B-axis datum.

Step 4 — Import Collision Geometry

Import Machine STEP File

Right-click each MTB node → Add Geometry → import the corresponding .step body from the Toyoda machine model package. Assign to the correct kinematic node.

Minimum Required Bodies

At minimum define: Column (Y+Z node), Spindle Head (Z node), Rotary Table (B node), Table Body / T-slots (X node). Add tool holders separately in the CAM session.

Assign Collision Sets

In MTB: Edit → Collision Sets. Create pairs: Spindle_Head ↔ Table, Spindle_Head ↔ Fixture, Tool ↔ Machine_Body. Exclude tool-holder vs. spindle (always touching).

Step 5 — Save and Validate

MTB Validation Checklist
✓ Move each axis to its min/max limits — no geometry overlap at limits
✓ Rotate B_AXIS to ±90° and ±180° — spindle/table clearance verified
✓ Home position (all zeros): no collision reported
✓ Machine coordinate origin matches control datum (G53 X0 Y0 Z0 = machine home)
✓ Save as .mtx — File → Export Machine → MTX format

4th Axis Pivot Setup in NX

Define B-Axis Center in CAM Setup

In Operation Navigator → MCS → Edit: set Rotary Axis to +Y vector. Set Pivot Point to the center of your pallet / rotary table (measured from part zero in G54).

B-Axis Pivot Offset Example

If your part zero (G54) is on the table face 200 mm above the table surface, and the B-axis center is at the table surface: Pivot offset = Y = −200 mm from G54 origin. Measure on the machine with an indicator.

Verify with Rotation Test

Create a single NX Point at the part origin. Set B=90°. The point should remain at the same machine XZ position after rotation (only machine coordinates change, not the WCS point). If it drifts, the pivot offset is wrong.

Tip — B Direction

Toyoda NH550SX follows the right-hand rule: positive B rotation is counter-clockwise viewed from above (+Y direction). Confirm with your machine's parameter sheet — some configurations invert this. Run G91 B90 F25 at slow feed and observe direction before using in production programs.

4th Axis Configuration

Indexing vs. Continuous Mode

3+1 Indexed (Most Common)

  • B moves to angle then clamps
  • Spindle machines in XYZ only
  • Requires M10 / M11
  • G-code G00 B90. M10
  • NX operation Fixed Contour
  • Axis in NX Tool Axis = +ZM

4-Axis Continuous

  • B moves simultaneous with XYZ
  • Table NOT clamped during cut
  • Requires M11 (unclamp)
  • G-code G01 X_ B_ F_
  • NX operation Variable Axis
  • Axis in NX Relative to Drive

Clamp / Unclamp M-Codes — NH550SX

M-CodeFunctionWhen to Use
M10B-Axis ClampAfter indexing B to target angle before any cutting
M11B-Axis UnclampBefore any B-axis motion (rapid or feed)
M19Spindle OrientBefore tool change (auto in ATC cycle)
M52Pallet ClampAfter pallet load / APC exchange
M53Pallet UnclampBefore APC exchange
Never Cut with B Unclamped

In 3+1 indexed mode, always verify M10 (clamp) is output before any X/Y/Z cutting motion. The NX post must insert M10 automatically after each B-axis index move. Cutting with the rotary unclamped will damage the clamp mechanism and produce scrap.

B-Axis in NX CAM — Tool Axis Settings

3+1 Indexed Operation

In any NX milling operation → Tool Axis tab → set to +ZM Axis. Then in the operation's Machine Control block, add B-axis angle as a parameter. The post will output the index move.

4-Axis Continuous Operation

Use Variable Contour operation. Tool Axis = Relative to Drive or Interpolate. Under Non-Cutting Moves, ensure B-axis retracts to safe position before transfers.

Set Rotary Axis in MCS

In CAM Setup → MCS → Rotary Axis: Direction = +YM vector. This tells NX the B-axis rotates about the Y direction of the machine coordinate system.

NX 2412 CAM Setup

CAM Session Initialization

Enter Manufacturing Application

Application → Manufacturing (or Ctrl+Alt+M). Select CAM configuration: cam_general. This loads the standard milling environment with 4-axis support.

Create CAM Setup

In Operation Navigator: right-click → Insert → Setup. Set MCS origin to your part datum. Under Machine Tool, select TOYODA_NH550SX from the library.

Configure MCS for B-Axis

In the MCS dialog → Rotary Axis tab: Axis = +Y, Pivot from MCS origin = actual distance from part zero to B-axis center (measure on machine). Enter as signed offset.

Assign Work Offset

Set G54 as the primary work offset. For multi-face 3+1 programs, use a single G54 at the B-axis center — the post will handle face-specific offsets via B-angle output. Avoid creating separate G54/G55/G56 per face unless your shop standard requires it.

Critical Post Events — Tcl Handlers

proc nh550sx_rotary_move { } — B-Axis Index with Clamp
# Called every time B-axis changes position (indexed mode)
proc MOM_rotary_axis_index { } {
    global mom_b_angle mom_prev_b_angle

    # 1. Retract Z before rotating
    MOM_do_template z_retract

    # 2. Output unclamp
    MOM_output_literal "M11"

    # 3. Output B rapid move
    MOM_output_literal "G00 B[format %.3f $mom_b_angle]"

    # 4. Dwell for B settle (optional, machine-dependent)
    # MOM_output_literal "G04 P500"

    # 5. Output clamp
    MOM_output_literal "M10"
}

Simulation Workflow — NX 2412

Step-by-step procedure for running machine simulation (ISV) and G-Code simulation in NX 2412 for the NH550SX 4-axis setup.

Method 1 — Integrated Simulation & Verification (ISV)

ISV runs the tool path directly inside NX using the MTB machine model. Best for catching collisions before posting.

Open ISV from Operation Navigator

Select one or more operations in the Operation Navigator. Right-click → Simulate → Simulate Machine. The ISV window opens with the machine model loaded.

Confirm Machine Loaded

In the ISV panel, verify Machine shows TOYODA_NH550SX. If blank: Machine panel → Load Machine → browse to your .mtx file. The 3D machine model should appear in the graphics window.

Set Stock and Fixture

In ISV: Setup tab → Stock Body → select your stock geometry from the part. Fixture → select fixture bodies. These are used for collision and material removal display.

Run Simulation

Press Play (▶) or use the step-forward button for single-block simulation. Use the Speed slider to control animation speed. Watch for red collision highlights on the machine model.

Review B-Axis Motion

At each B-axis index event, the simulation should show: (1) linear axes retract, (2) B rotates, (3) linear axes approach new position. If the machine collides during B rotation, add more retract clearance in non-cutting moves.

Check Collision Report

After simulation: Results tab → Collision List. Expand each collision to see which bodies collide and at which program block. Fix by editing the operation's retract/approach clearance, then re-simulate.

Method 2 — G-Code Simulation

G-Code Sim reads the posted NC file. Use this to verify the exact code that will run on the machine.

Post the NC Program

In Operation Navigator: select all operations → right-click → Post Process. Select post nh550sx_fanuc30i. Output to a known directory (e.g., C:\NC\NH550SX\).

Open G-Code Sim

Menu → Manufacturing → G-Code Simulation. Load the .nc file: File → Open NC File. Select machine: TOYODA_NH550SX (same .mtx as ISV).

Map Work Offsets

In G-Code Sim: Offsets tab → enter G54 values matching your control setup page. These must match the actual machine offsets for accurate position verification.

Run and Verify

Press Cycle Start. The simulation reads G-code block-by-block. B-axis moves will animate the rotary table. The DRO panel shows live machine coordinates — compare to expected G53 positions.

Compare to Nominal

After completing the simulation: Compare tab → load nominal part model → run deviation analysis. Deviations shown as color map. Max allowable deviation = your part tolerance minus half your stock allowance.

Simulation Best Practice

Always run ISV first (catches NX-level path issues), then post and run G-Code Sim (catches post processor issues). Both must pass before sending a new program to the machine. G-Code Sim is the final gatekeeper.

Adding Fixture Geometry to ISV

Create Fixture Bodies in Part

Model your vise, tombstone, or custom fixture in the NX part file as solid bodies. Name them clearly: FIXTURE_VISE, TOMBSTONE_400H, etc.

Assign in CAM Setup

In Operation Navigator → CAM Setup → Edit → Simulation tab → Fixture Bodies → select your fixture solids. These attach to the B-axis node during simulation.

Verify B-Axis Attachment

In ISV, manually jog B to ±90°. Confirm the fixture body rotates with the table (it should, since it's assigned as fixture which attaches to the B-node). If it stays fixed, re-check the MTB kinematic assignment.

Tombstone Height Warning

A 400 mm tall tombstone on the NH550SX table can reduce effective swing clearance to zero at B=±90°. Always model your tallest fixture and check the spindle/head collision at ±90° before relying on G28 Z-only retract. You may need G28 X as well.

Tool Path Verification

NX Verify Tool Path

Run Verify on All Operations

Select all ops in Navigator → right-click → Verify Tool Path. In the Verify dialog: enable Gouge Check, Excess Material, and IPW (In-Process Workpiece).

Check for Gouges

Verify colors: Green = cut, Red = gouge, Yellow = excess. Any red areas must be investigated. Common cause in 4-axis: tool axis not correctly aligned to face normal at the index angle.

Verify B-Axis Undercut Risk

In 4-axis continuous, the tool can undercut the workpiece if B drives the part surface back into the tool. Enable Rotary Undercut Check in Verify settings. Any undercut will show as a gouge.

Review IPW Between Ops

Use the IPW (in-process workpiece) to carry material state between operations. This shows actual remaining stock after each op. Critical for planning B-axis indexing order — machine faces with most stock first.

Post-Simulation Signoff Checklist

  • ISV ran to completion with 0 collisions reported
  • G-Code Sim ran to completion with 0 collisions reported
  • All B-axis index moves preceded by Z retract to G28
  • All B-axis index moves followed by M10 clamp before any cutting
  • Program header contains G17 G40 G49 G80 G90 safety block
  • Tool length offsets match presetter data (H numbers)
  • Work offset G54 verified to match machine setup sheet
  • Verify Tool Path shows 0 gouges on all operations
  • IPW shows correct remaining stock between each operation group
  • Coolant codes (M08/M09) present in each operation
  • Feed rates reviewed — no excessively high 4-axis combined feedrate
  • Tool change sequences verified — G91 G28 Z0 before each T_ M6
  • Program tested by experienced machinist or ME before first run
  • First-article inspection planned for first production piece

All canned cycles: cancel with G80 before non-hole moves
For 4-axis drilling: use G98 (return to initial Z level) at all B positions

Pre-Run Checklist — NH550SX 4th Axis

Complete before running any new 4-axis program on the NH550SX for the first time.

NX CAM / Simulation

  • Machine model TOYODA_NH550SX loaded in ISV — kinematic tree verified
  • ISV completed without collisions for all operations
  • G-Code Simulation completed without collisions using posted NC file
  • NX Verify shows zero gouges — all operations
  • B-axis pivot offset confirmed against physical machine measurement
  • Tool holders modeled in NX with correct gauge length from presetter
  • Fixture geometry added to simulation — all clamps and risers included
  • Tombstone / fixture swing envelope cleared at B = 0, ±45, ±90, ±135, ±180

Post Processor / NC Code

  • NC program reviewed in text editor — B values plausible for each face
  • M11 (unclamp) present before every B motion
  • M10 (clamp) present after every B index, before first cutting move
  • G91 G28 Z0 executed before every B rotation
  • G91 G28 X0 Y0 executed before B rotation (verify sufficient with sim)
  • Tool change sequence: G28 Z → T_ M6 → G43 H_ — correct order
  • Safety block G17 G40 G49 G80 G90 at program start
  • M30 at end of program
  • Feed rates within machine limits (B rapid ≤ 900 deg/min, cuts per data)

Machine Setup

  • Work offset G54 set and verified (probe or indicator at B=0)
  • G54 origin confirmed to be at or referenced to B-axis center
  • All tools loaded, measured on presetter, offsets entered (H and D numbers)
  • Fixture torqued to spec on rotary table — all T-bolts checked
  • B-axis zero return performed (reference point return G28 B0)
  • Pallet clamped — M52 confirmed if APC in use
  • Chip conveyor and coolant running — drain not blocked
  • Machine door closed and safety interlock armed

First-Run Protocol

  • DRYRUN mode enabled for first full run — verify positions visually
  • Single-block mode ON — advance block-by-block through first B index
  • Feed Hold ready — operator hand on button through first B rotation
  • After DRYRUN: reset, remove dryrun, run with 50% override
  • First part inspected fully — all features on all B-faces measured
  • Program signed off by ME or lead machinist before production release
No Shortcuts on First Run

Every new 4-axis program must complete DRYRUN before cutting. B-axis rotation with fixtures in the envelope is one of the highest-risk machine moves. A collision at B-axis rapid speed will damage the rotary table clamp, the spindle, and potentially the machine. The 5 minutes for DRYRUN is always worth it.
