Probe Power & Activation (DMG Mori Manual)

🔌M144 / M145 — Probe ON/OFF

( ACTIVATE SPINDLE PROBE ) M144 ( Probe Power ON — transmitter activated ) G4 P1.0 ( Dwell 1 sec — allow probe to initialize ) ( ... probing cycle ... ) ( DEACTIVATE SPINDLE PROBE ) M145 ( Probe Power OFF )
M144 activates the spindle probe transmitter. Always dwell after M144 before calling any G320/G370 cycle. M145 deactivates. These are DMG Mori NHX5000 manual-specified M-codes.

🔧Probe Orientation (Required)

( ORIENT SPINDLE FOR PROBE USE ) M19 ( Spindle orient — align probe stylus ) M144 ( Probe ON ) G4 P1.0 ( Wait for probe ready ) G91 G28 Z0 ( Return to ref Z )
Do NOT rotate spindle (S-code) while probe is installed. M19 orient only.

⚙Probe Setup Program Template

O1000 ( PROBE SETUP PROGRAM ) G90 G94 G17 ( Absolute, feed/min, XY plane ) G20 ( Inch mode ) G40 G49 G80 ( Cancel comp/TLC/canned ) T50 M6 ( Load probe — tool 50 typical ) M19 ( Spindle orient ) M144 ( Probe ON ) G4 P1.0 ( Dwell 1 sec ) ( ... G320/G370 cycles here ... ) M145 ( Probe OFF ) G91 G28 Z0 ( Z home ) M30 ( Program end )

G320 — Automatic Measurement Cycle (DMG Mori Native)

▶G320 Syntax — Full Format

G320 X_ Y_ Z_ D_ F_ W_ Q_ L_ S_ ( X = Target X position ) ( Y = Target Y position ) ( Z = Target Z position ) ( D = Measurement direction 1=+X 2=-X 3=+Y 4=-Y 5=+Z 6=-Z ) ( F = Feed rate (in./min) ) ( W = Work offset number to write result e.g. W54 = G54, W55 = G55, etc. ) ( Q = Axis to write offset (1=X 2=Y 3=Z) ) ( L = Measurement distance (search stroke) ) ( S = Skip signal selection )

📈G320 — Measure X Origin (Single Surface)

( SET G54 X-ZERO FROM PART EDGE ) M144 ( Probe ON ) G4 P1.0 G90 G0 ( Absolute rapid ) G0 X-1.0 Y0. Z0.5 ( Approach safe position ) G320 X0. Y0. Z0.5 D1 F10. W54 Q1 L0.5 ( G320 probes in +X direction, writes result to G54 X offset automatically via W54 Q1 ) M145 ( Probe OFF )

📈G320 — Measure Y Origin (Single Surface)

( SET G54 Y-ZERO FROM PART FRONT FACE ) M144 G4 P1.0 G0 X0. Y-1.0 Z0.5 G320 X0. Y0. Z0.5 D3 F10. W54 Q2 L0.5 ( D3 = probe in +Y direction W54 Q2 = write to G54 Y offset ) M145

📈G320 — Measure Z Surface

( SET G54 Z-ZERO FROM TOP OF PART ) M144 G4 P1.0 G0 X0. Y0. Z1.0 G320 X0. Y0. Z0. D6 F5. W54 Q3 L0.5 ( D6 = probe in -Z direction W54 Q3 = write to G54 Z offset ) M145

📈G320 — Boss / Center X (Two Touches)

( FIND CENTER OF BOSS IN X ) ( Touch -X side first ) M144 G4 P1.0 G0 X-1.25 Y0. Z-0.5 G320 D1 F10. L1.0 #100=#5001 ( Save +X touch in #100 ) ( Touch +X side ) G0 X1.25 G320 D2 F10. L1.0 #101=#5001 ( Save -X touch in #101 ) #102=[#100+#101]/2 ( Calc center ) G10 L2 P1 X#102 ( Write center to G54 X ) M145
#5001 = last measurement result variable (Fanuc Macro B).
G370 — Reference Face Measurement (DMG Mori Native)

▶G370 Syntax

G370 X_ Y_ Z_ D_ F_ W_ Q_ L_ ( G370: measures from a reference surface. Used to update offsets relative to a known reference (master) position. D = direction same as G320: 1=+X 2=-X 3=+Y 4=-Y 5=+Z 6=-Z W = work offset to update Q = axis (1=X 2=Y 3=Z) )
G370 is used when you need to re-reference to a datum surface rather than set an absolute zero. The cycle measures the surface and updates the offset relative to the reference point stored from the G323 sensor offset calibration.

📈G370 — Re-Reference Z from Datum Surface

( RE-REFERENCE Z FROM FIXTURE DATUM PAD ) M144 G4 P1.0 G0 X0. Y0. Z1.0 G370 X0. Y0. Z0.1 D6 F5. W54 Q3 L0.5 ( Probes down -Z, updates G54 Z offset relative to calibrated sensor reference ) M145

📈G370 — Re-Reference X from Datum

( RE-REFERENCE X FROM FIXTURE SIDE PAD ) M144 G4 P1.0 G0 X-1.0 Y0. Z0. G370 X-0.5 Y0. Z0. D1 F10. W54 Q1 L0.5 ( Probes +X to datum, updates G54 X ) M145

G323 — Sensor Offset Calibration (DMG Mori Native)

▶G323 Syntax

G323 F_ L_ ( G323: Calibrates spindle probe tip offset using the table-mounted reference tool sensor (TLS/reference sphere). F = probing feed rate L = search stroke distance Result stored in machine parameters / probe offset register )
Run G323 whenever the probe is changed, stylus is swapped, or after any crash. This establishes the probe tip position relative to machine coordinates. Must be run before G320/G370 cycles produce accurate results.

📈G323 — Probe Calibration Routine

( PROBE CALIBRATION — RUN AFTER PROBE INSTALL ) O0999 G90 G20 T50 M6 ( Load probe ) M19 ( Spindle orient ) M144 ( Probe ON ) G4 P1.0 ( Position over table reference sensor ) G0 X[table_sensor_X] Y[table_sensor_Y] Z1.0 G323 F5. L0.5 ( Stores probe offset in machine register ) M145 ( Probe OFF ) G91 G28 Z0 M30

⚠G323 — When to Run

ALWAYS run G323 calibration after:
• Installing or re-installing the probe
• Replacing probe stylus
• Any probe crash or over-travel
• Machine startup / power-on sequence
• Any change to probe tool offset (T50)
Store the G323 calibration run as a sub-program and call it as part of your setup macro before any G320/G370 measurement cycles.

📈Tool Length — On-Machine TLS Measurement

( MEASURE TOOL LENGTH — NHX5000 TLS CYCLE ) ( Positions over table-mounted tool sensor ) O0800 ( TOOL LENGTH MEASURE ) G90 G20 T5 M6 ( Load 1" end mill — tool 5 ) S200 M3 ( Slow spindle for TLS measurement ) G43 H5 G0 Z4. ( Apply current H5, retract Z ) ( Rapid to TLS position ) G0 X[TLS_X] Y[TLS_Y] G0 Z1.0 ( Measure — result writes to H offset ) G320 D6 F5. L1.0 #120=#5003 ( Capture measured Z ) G10 L1 P5 Z#120 ( Write to H5 offset ) M5 G91 G28 Z0 M30
Replace [TLS_X] and [TLS_Y] with your machine's table sensor position. Confirm actual TLS cycle with your DMG Mori documentation — some machines use a custom macro instead of G320.

Tool Breakage Detection — NHX5000

⚠Breakage Check — Concept

( TOOL BREAKAGE CHECK — AFTER CRITICAL OP ) ( Compare current tool length to known good ) ( Uses G320 D6 to touch TLS, compare to H offset ) #121=3.500 ( Nominal tool length ) #123=0.030 ( Breakage tolerance — 0.030" ) ( Measure tool after operation ) G320 D6 F5. L1.0 #120=#5003 ( Measured length ) #122=[#121-#120] ( Length loss ) IF [#122 GT #123] GOTO 9990 GOTO 9989 N9990 ( TOOL BROKEN — ALARM ) #3000=102 (TOOL 5 BROKEN - CHECK) N9989
Always use a breakage tolerance appropriate for the tool diameter. For a 1" end mill, 0.030" is a typical minimum breakage threshold.

📋Breakage Check Parameter Reference

VariableDescriptionExample

#121Nominal tool length3.500

#123Breakage threshold0.030

Set #3000 with a message string to display a meaningful alarm. The machine will feed-hold and show the message on the operator screen.
Tool Diameter / Radius Offset — NHX5000

⌬Tool Radius Offset — G41 / G42

( TOOL RADIUS COMPENSATION ) ( D offset = tool radius stored in D register ) ( 1" end mill: nominal radius = 0.500" ) G41 D5 ( Left compensation — climb milling ) G42 D5 ( Right compensation — conventional ) G40 ( Cancel radius compensation ) ( Set D5 radius offset via G10: ) G10 L1 P5 R0.500 ( Nominal — 1" dia / 2 ) ( Adjust R for measured actual diameter )

📈Measure Tool Diameter — Two-Touch Method

( MEASURE ACTUAL TOOL DIAMETER ) ( Touch +X then -X on tool flutes ) ( Tool must be stopped — probe at flute height ) M144 G4 P1.0 ( Touch +X flute ) G0 X-0.75 Y0. Z[flute_Z] G320 D1 F5. L0.5 #130=#5001 ( Save +X contact ) ( Touch -X flute ) G0 X0.75 G320 D2 F5. L0.5 #131=#5001 ( Save -X contact ) #132=[#130-#131] ( Measured diameter ) ( Write actual radius to D offset ) G10 L1 P5 R[#132/2] M145
Tool must be stationary during diameter measurement. Index spindle to a consistent angular position (M19) for repeatable results across multiple measurements.

Offset Writing — G10 Reference

📝G10 — Work Offset Write (G54–G59)

( G10 WORK OFFSET WRITE FORMAT ) ( L2 = work offset, P = offset number ) ( P1=G54, P2=G55, P3=G56, P4=G57, P5=G58, P6=G59 ) G10 L2 P1 X0. ( Write G54 X zero ) G10 L2 P1 Y0. ( Write G54 Y zero ) G10 L2 P1 Z0. ( Write G54 Z zero ) G10 L2 P1 X#102 ( Write computed center to G54 X ) ( Extended offsets: G54.1 P1 through P48 ) ( L20 = extended work offset ) G10 L20 P1 X0. ( G54.1 P1 X zero )

📝G10 — Tool Length Offset Write

( G10 TOOL OFFSET WRITE FORMAT ) ( L1 = geometry offset, L11 = wear offset ) ( P = tool number ) G10 L1 P5 Z3.500 ( Set H5 length = 3.500" ) G10 L11 P5 Z0. ( Clear H5 wear = 0 ) G10 L1 P5 R0.500 ( Set D5 radius = 0.500" ) G10 L11 P5 R0. ( Clear D5 radius wear = 0 ) ( Write measured result from variable ) G10 L1 P5 Z#120 ( H5 = measured tool length ) G10 L1 P5 R[#132/2] ( D5 = half measured diameter )

📋G10 L-Code Reference

L CodeDescriptionAxis
G10 L1Tool geometry offset (H/D)Z = length, R = radius
G10 L11Tool wear offsetZ = length wear, R = radius wear

In-Process Inspection — NHX5000

📈In-Process X/Y Center — Bore or Boss

( IN-PROCESS: FIND CENTER AFTER ROUGH BORE ) ( Four-touch method — +X -X +Y -Y ) M144 G4 P1.0 ( Touch +X ) G0 X1.1 Y0. Z[probe_Z] G320 D2 F10. L0.5 #100=#5001 ( Touch -X ) G0 X-1.1 G320 D1 F10. L0.5 #101=#5001 #102=[#100+#101]/2 ( Touch +Y ) G0 X0. Y1.1 G320 D4 F10. L0.5 #103=#5002 ( Touch -Y ) G0 Y-1.1 G320 D3 F10. L0.5 #104=#5002 #105=[#103+#104]/2 ( Write found center to G54 ) G10 L2 P1 X#102 Y#105 M145

📈In-Process Z Surface Check

( VERIFY Z AFTER FACING PASS ) ( Compare measured Z to nominal depth ) #110=-0.500 ( Nominal Z depth ) #111=0.002 ( Tolerance ) M144 G4 P1.0 G0 X0. Y0. Z0.5 G320 X0. Y0. Z0.1 D6 F5. L0.5 #103=#5003 ( Measured Z surface ) #105=[#103-#110] ( Deviation ) IF [ABS[#105] GT #111] GOTO 9999 GOTO 9998 N9999 #3000=103 (Z DEPTH OUT OF TOLERANCE) N9998 M145
